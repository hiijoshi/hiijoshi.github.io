Free Tools

I'm building a set of free, practical tools for students, developers, and small business owners — focused on things people actually search for and need quickly, without sign-ups or clutter.

Tools In Progress

The following tools are currently in development and will be added here as each one goes live, fully working and tested:

  • CGPA Calculator — convert grades and calculate your cumulative GPA for Indian university grading systems
  • GST Calculator — quickly calculate GST-inclusive and GST-exclusive prices for invoices
  • Sitemap Checker — validate your sitemap.xml structure and check for common errors before submitting to Search Console
  • Resume ATS Checker — check if your resume format is readable by applicant tracking systems
  • AWS Cost Calculator — estimate monthly hosting costs for common AWS Lightsail and EC2 setups

Why These Tools

I picked these specifically because I've needed each one myself while working on real projects — calculating grades, preparing invoices, checking sitemaps before indexing, and estimating hosting costs before deploying. Instead of guessing what's useful, I'm building what I actually use.

In the meantime, you can read practical guides on these exact topics on my blog — including sitemap setup, AWS deployment, and AdSense readiness.
